# 需求规格说明

## 应用概述

MyWorkOut 是一款个人健身日志应用，以"周"为时间单位管理训练记录。
当前主要运行方式是部署在 GitHub Pages 的 PWA，在 iPhone 上添加到主屏幕使用。

## 功能清单

### 菜单一：「我的」— 训练配置

- 按周一至周日分别配置训练计划
- 每天可配置：肌肉群、动作名称、配重(kg)、组数、每组次数
- 支持添加、编辑、删除动作（删除 = 归档，历史打卡保留）
- 所有配置持久化保存

### 菜单二：「健身记录」— 训练打卡

#### 日期导航
- 顶部横向排列周一~周日 7 张日期卡片
- 今天高亮，可点击任意卡片切换日期
- 左右箭头切换上一周/下一周
- 日历图标打开日期选择器，可跳转到任意日期

#### 打卡交互
- 显示当天已配置的训练动作
- 每完成一组训练，点击「完成一组」按钮打卡
- 系统自动记录：组号、重量、完成时间戳
- 自动计算与上次打卡的间隔时间（格式：2m6s）

#### 重量调整
- 训练中可调整动作配重
- 调整后自动同步到「我的」配置
- 记录变更时间，可追踪重量变化历史
- 支持提前结束训练，未完成时二次确认

#### 历史查看
- 查看过去任意日期的训练记录
- 历史记录只读展示
- 显示完成的组数、每组的重量和时间间隔
- 动作改名或归档后，历史仍显示打卡当时的动作名称

### 菜单三：「体重」— 体重趋势

- 可按任意日期记录体重，一天保留一条，重复保存覆盖
- 显示最新体重、近 28 天变化和每周变化速度
- 折线图支持 30 天 / 90 天 / 全部
- 每周下降 0.25–0.75 kg 评估为「良好」
- 低于 0.25 kg/周为「偏慢」，超过 0.75 kg/周为「偏快」，上升为「上升」
- 记录不足两次或跨度不足 7 天时显示「数据不足」
- 支持编辑和删除历史记录

### 菜单四：「饮食」— 膳食指南

- 显示当前阶段的每日总热量、蛋白质、碳水、脂肪
- 显示三大营养素换算热量和比例
- 显示每日固定食材、数量、单位和称重方式
- 支持编辑阶段名称、开始日期、热量、宏量、说明和食材清单
- 首次进入自动生成初始模板：
  - 2,100 kcal / 蛋白质 180 g / 碳水 220 g / 脂肪 56 g
  - 鸡胸肉 600 g 生重；鸡蛋 3 个（去壳约 150 g）；螺纹辣椒 200 g 生重；
    白米 270 g 生米（煮熟约 675–810 g）；食用油 32 g
- 模板按 38 岁男性、170 cm、90 kg、每周力量训练 4 次、久坐办公生成
- 页面提示额外水果、蔬菜和奶类需要计入热量

### 数据安全

- 数据保存在当前设备的浏览器 IndexedDB
- 训练、体重、膳食数据统一导出 JSON 备份、复制备份内容、导入恢复
- 导入会覆盖当前数据，必须二次确认

### 运行方式

- 部署在 GitHub Pages，通过 iPhone Safari「添加到主屏幕」使用
- 支持离线打开和自动更新

## 设计原则

- 简洁、直观
- 视觉方向：暖白 (#F2EFE8) + 墨黑 (#181715) + 焦橙 (#C9451B)
- 当前动作使用深色焦点卡，主操作只保留一个强调色按钮
- 操作反馈及时、清晰

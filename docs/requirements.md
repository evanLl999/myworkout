# 需求规格说明

## 应用概述

MyWorkOut 是一款 Windows 桌面健身日志应用，以"周"为时间单位管理个人健身记录。

## 功能清单

### 菜单一：「我的」— 训练配置

- 按周一至周日分别配置训练计划
- 每天可配置：肌肉群、动作名称、配重(kg)、组数、每组次数
- 支持添加、编辑、删除动作
- 所有配置持久化保存

### 菜单二：「健身记录」— 训练打卡

#### 日期导航
- 顶部横向排列周一~周日 7 张日期卡片
- 今天高亮，可点击任意卡片切换日期
- 左右箭头切换上一周/下一周
- 日历图标打开日期选择器，可跳转到任意日期

#### 打卡交互
- 显示当天已配置的训练动作
- 每完成一组训练，点击「完成一组」按钮打卡
- 系统自动记录：组号、重量、完成时间戳
- 自动计算与上次打卡的间隔时间（格式：2m6s）

#### 重量调整
- 训练中可调整动作配重
- 调整后自动同步到「我的」配置
- 记录变更时间，可追踪重量变化历史

#### 历史查看
- 查看过去任意日期的训练记录
- 历史记录只读展示
- 显示完成的组数、每组的重量和时间间隔

## 设计原则

- 简洁、直观
- 主色调：淡蓝色 (#5B9BD5)
- 操作反馈及时、清晰

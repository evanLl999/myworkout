# 需求规格说明

## 应用概述

MyWorkOut 是一款个人健身日志应用，以"周"为时间单位管理训练记录。
当前主要运行方式是部署在 GitHub Pages 的 PWA，在 iPhone 上添加到主屏幕使用。

## 功能清单

### 菜单一：「我的」— 训练配置

- 按周一至周日分别配置训练计划
- 每天可配置：肌肉群、动作名称、配重(kg)、组数、每组次数
- 支持添加、编辑、删除动作（删除 = 归档，历史打卡保留）
- 所有配置持久化保存

### 菜单二：「健身记录」— 训练打卡

#### 日期导航
- 顶部横向排列周一~周日 7 张日期卡片
- 今天高亮，可点击任意卡片切换日期
- 左右箭头切换上一周/下一周
- 日历图标打开日期选择器，可跳转到任意日期

#### 打卡交互
- 显示当天已配置的训练动作
- 每完成一组训练，点击「完成一组」按钮打卡
- 系统自动记录：组号、重量、完成时间戳
- 自动计算与上次打卡的间隔时间（格式：2m6s）

#### 重量调整
- 训练中可调整动作配重
- 调整后自动同步到「我的」配置
- 记录变更时间，可追踪重量变化历史
- 支持提前结束训练，未完成时二次确认

#### 历史查看
- 查看过去任意日期的训练记录
- 历史记录只读展示
- 显示完成的组数、每组的重量和时间间隔
- 动作改名或归档后，历史仍显示打卡当时的动作名称

### 数据安全

- 数据保存在当前设备的浏览器 IndexedDB
- 支持导出 JSON 备份、复制备份内容、导入恢复
- 导入会覆盖当前数据，必须二次确认

### 运行方式

- 部署在 GitHub Pages，通过 iPhone Safari「添加到主屏幕」使用
- 支持离线打开和自动更新

## 设计原则

- 简洁、直观
- 主色调：淡蓝色 (#5B9BD5)
- 操作反馈及时、清晰

# UI 设计规范

## 配色方案

| 变量 | 色值 | 用途 |
|------|------|------|
| `--primary` | `#5B9BD5` | 主色 - 按钮、选中态、强调元素 |
| `--primary-light` | `#D6E6F5` | 浅蓝背景 - 标签、悬停态 |
| `--primary-dark` | `#3A7CC3` | 深蓝 - 侧边栏渐变、悬停态 |
| `--bg` | `#F5F8FC` | 页面背景 |
| `--white` | `#FFFFFF` | 卡片背景 |
| `--text` | `#333333` | 主文字 |
| `--text-secondary` | `#888888` | 次要文字 |
| `--success` | `#52C41A` | 完成状态 |
| `--border` | `#E0E6ED` | 边框、分割线 |

## 布局

```
┌──────────┬─────────────────────────────────┐
│ Sidebar  │  Main Content                   │
│          │                                 │
│ 180px    │  flex: 1                        │
│ 淡蓝渐变  │  浅蓝背景                         │
│          │                                 │
└──────────┴─────────────────────────────────┘
```

## 侧边栏

- 宽度：180px
- 背景：`primary` → `primary-dark` 线性渐变
- Logo 区域：内边距 24px，白色 18px 粗体
- 导航项：圆角 8px，白色半透明文字
- 悬停：半透明白色背景
- 选中：高亮白色背景 + 加粗

## 组件规范

### 按钮
- 主按钮：`primary` 背景，白色文字，圆角 8px
- 轮廓按钮：白色背景，`primary` 边框和文字
- 小按钮：padding 4px 12px，字号 13px
- 危险按钮：红色背景

### Tab 标签
- 横向排列，等宽
- 默认灰色文字，无背景
- 选中：`primary` 背景，白色文字加粗

### 日期卡片
- 等宽横向排列，间距 8px
- 默认白色背景，灰色边框
- 今天：`primary` 边框 + 外阴影
- 选中：`primary` 背景

### 训练动作卡片
- 白色背景，圆角 12px
- 头部：动作名（左）+ 肌肉群标签（右）
- 信息行：目标组数、次数、配重
- 操作区：打卡按钮 + 休息计时 + 重量调整

## 字体

- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Microsoft YaHei', sans-serif`
- 标题：22px / 600 字重
- 正文：14-15px
- 次要文字：13px / `text-secondary`

## 间距

- 页面内边距：32px
- 卡片内边距：16-20px
- 组件间距：12px、24px
- 卡片圆角：10-12px

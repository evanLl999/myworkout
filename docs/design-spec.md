# UI 设计规范

## 视觉方向

「运动杂志感」：暖白纸张、墨黑结构、焦橙强调。

- 温暖但不软：用米白和暖灰做底，用墨黑建立层级。
- 高对比但克制：只有主操作、当前动作和进度使用强调色。
- 信息像训练日志：英文小标题、等宽数字、清晰的日期与组数。
- 不用 emoji 充当图标，不用大面积渐变，不用通用淡蓝卡片。

## 颜色

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#F2EFE8` | 页面底色 |
| `--surface` | `#FFFCF7` | 卡片、顶栏 |
| `--surface-2` | `#F7F2EA` | 输入框、次级按钮 |
| `--ink` | `#181715` | 主文字、当前动作卡、底部导航 |
| `--muted` | `#7C756B` | 次要文字 |
| `--line` | `#E4DED4` | 边框、分割线 |
| `--primary` | `#C9451B` | 强调色，可在顶部调色盘切换 |
| `--success` | `#1E7A55` | 完成状态 |
| `--danger` | `#C84437` | 删除、错误 |

强调色预设：焦橙、钴蓝、森林、紫罗兰、玫瑰、琥珀。调色盘只改强调色，不改背景和墨黑结构。

## 字体

- 正文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 小标题/数字：`ui-monospace, "SFMono-Regular", Menlo, monospace`
- 页面标题：32px / 760，字距 `-0.045em`
- 卡片标题：21px / 720
- 英文 overline：9px，字距 `0.18em`，全大写
- 数字使用 `font-variant-numeric: tabular-nums`

## 布局

```
┌───────────────────────────┐
│ Topbar 64px（品牌 + 调色）  │
├───────────────────────────┤
│ Page 20px 内边距            │
│  - 页面标题                  │
│  - 周卡片（导航 + 7 天）      │
│  - 训练状态卡                │
│  - 动作卡列表                │
├───────────────────────────┤
│ 浮动 Dock（训练/体重/饮食/计划）│
└───────────────────────────┘
```

- 手机全宽；桌面最大 520px 居中，带圆角和阴影，像一个独立的 App 画框。
- 底部 Dock 固定，宽度 `min(100% - 24px, 496px)`，避开 iPhone 安全区。
- 页面底部留出 `108px + safe-area`，保证最后一张卡能滚到 Dock 上方。

## 组件

### 周视图
- 白色周卡片，包含周标题、前后切换、日历按钮和 7 天日期条。
- 日期条使用 `周一 … 周日`，选中日为墨黑药丸，日期白色，底部一个强调色圆点。
- 今天未选中时，星期文字和圆点使用强调色。

### 训练状态卡
- 未开始：白色卡片，标题「准备好开始了吗」，一个全宽强调色「开始训练」按钮。
- 进行中：墨黑卡片，左上 `IN PROGRESS`，大号等宽计时，组数进度条，LIVE 徽标。
- 已完成：白色卡片，绿色 DONE 徽标，总用时/完成组数/额外用时。
- 进行中时，「提前结束」为描边按钮，重置为文字链接；主要动作仍是动作卡里的打卡按钮。

### 休息计时
- 首次打卡后才出现。
- 吸顶在顶栏下方，浅色背景带 + 墨黑药丸，显示「休息中 01:23」。
- 训练完成时药丸变绿，显示「训练完成」。

### 动作卡
- 默认：暖白卡片，20px 圆角，细边框和轻阴影。
- 当前动作：墨黑背景、白色文字、强调色进度和打卡按钮，是页面唯一的大深色焦点。
- 未完成必练：淡暖色边框 + 肌肉群使用强调色。
- 已完成：降低透明度，右上角绿色对勾。
- 已归档：灰色虚线边框 + 「已删除」标签。
- 信息层级：动作名 → 组/次/kg 大数字 → 分段进度 → 重量步进器 + 「完成第 N 组」。
- 打卡记录：时间线形式，左侧小圆点，等宽时间，右侧间隔药丸。

### 计划页
- 顶部 7 个日期标签，选中为墨黑药丸。
- 计划卡显示肌肉群、必练/选练、动作名、组数/次数/重量、排序号和编辑/删除图标。
- 空计划显示图标、说明和「添加第一个动作」按钮。
- 添加/编辑使用底部抽屉，不跳页；背景滚动锁定。

### 底部抽屉
- 背景遮罩 + 模糊；手机从底部滑入，桌面居中。
- 顶部拖动条、英文 overline、标题和关闭按钮。
- 表单字段使用暖灰输入框，聚焦时强调色边框。
- 底部固定「取消 / 保存」，保存中禁用。

### 日历
- 底部抽屉，显示「2026年 10月」。
- 周标题使用 `周一 … 周日`。
- 选中日为墨黑圆形，今天在日期下方显示强调色圆点。

### 数据与备份
- 独立暖白卡片，`DATA / LOCAL ONLY` 标记。
- 说明数据只在本机，提供「导出备份」「复制」「导入」三个操作。

### 体重趋势页
- 深色 Hero：最新体重、评估徽标、近 28 天周速度和变化量。
- 折线图用强调色线条 + 同色渐变面积，网格和坐标使用低透明度白色。
- 目标体重以绿色虚线显示，目标值标在右侧；目标体重可设置/修改/清除。
- 目标行提供「目标线」绿色开关；关闭后隐藏目标线和目标值对纵轴的影响，开关状态持久化。
- 范围切换：30 天 / 90 天 / 全部；评估固定按最近 28 天。
- 评估徽标：良好为绿色，偏快为琥珀，上升为红色，数据不足为低对比白。
- 历史记录为暖白卡片，按日期倒序；点击行编辑，编辑抽屉里提供删除。
- 标准提示：「每周下降 0.25–0.75 kg」，并注明仅作趋势参考。

### 膳食指南页
- 暖白 Hero：大号每日总热量、阶段药丸、身体数据说明。
- 三大营养素用一条堆叠比例条 + 三张并排宏量卡：
  - 蛋白质：强调色
  - 碳水：琥珀
  - 脂肪：暖灰
- 每张卡显示克数、换算 kcal 和百分比。
- 每日食材为暖白列表卡：食材名 + 称重方式 + 数量/单位。
- 编辑阶段使用底部抽屉：阶段名、开始日期、总热量、三大营养素、说明和食材清单。
- 阶段历史使用底部抽屉：列出旧阶段、当前标记和切换操作；新建阶段复制当前配方。
- 食材编辑卡分三层：名称 + 删除；数量 + 单位；称重说明占整行。
- 底部提示额外水果、蔬菜和奶类需要计入热量，并注明不是医疗处方。

### 底部导航
- 四项：训练、体重、饮食、计划。
- 图标分别使用哑铃、趋势线、碗和滑杆；选中项为墨黑药丸。

## 动效

- 页面进入只做轻微淡入，不使用会影响 fixed 层级的 transform。
- 抽屉 0.32s 滑入，遮罩 0.2s 淡入。
- 打卡粒子使用强调色、暖金、米白和绿色，控制在 14 个左右，不做整页抖动。
- 支持 `prefers-reduced-motion`。

## 可访问性

- 图标按钮必须有 `aria-label`。
- 触控目标不小于 44px。
- 正文与背景保持足够对比；深色卡上的次要文字不低于 50% 白色。
- 日期、计划标签和分段控件提供选中状态语义。
